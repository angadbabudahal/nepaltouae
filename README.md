# Nepal to Dubai Visit Visa Landing Page

Official responsive landing page and inquiry system for **Brothers Jet Set Go Travels & Services Pvt. Ltd.** offering full visit visa packages from Nepal to Dubai (UAE).

## Features
- **Modern Responsive Design**: Luxury dark emerald and gold theme tailored for both desktop and mobile screens.
- **Mobile View Toggle**: Built-in 390px mobile viewport simulator for testing.
- **Interactive Inquiry Modal**: Dynamic package inquiry form with automated WhatsApp redirect.
- **WhatsApp & Call Direct Integration**: Direct communication channels to `+977 981-6386563`.
- **Location & Maps**: Direct integration with Google Maps ([Itahari Branch](https://maps.app.goo.gl/bKUNihunXzy4SJTn6)).
- **Comprehensive Sections**: What's Included, Pricing Breakdown, Step-by-step Process, Required Documents, Trust Indicators, and Interactive FAQs.

## Quick Start

### Running Locally
Run the built-in Node.js static server:
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack
- HTML5 & Vanilla JavaScript
- Tailwind CSS (via CDN)
- Custom CSS (`style.css`)
- Zero-dependency Node.js HTTP server (`server.js`)
